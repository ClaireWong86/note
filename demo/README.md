# 🎬 文本到视频 Demo

一个简单但真正能生成视频的演示应用！输入文本 → 生成语音 → 合成视频。

## ✨ 功能特点

- 🎤 **TTS语音合成** - 自动生成中文语音
- 🎨 **渐变背景** - 漂亮的彩色渐变背景
- 📝 **文字自动排版** - 智能换行和居中显示
- 🎬 **MP4视频导出** - 标准视频格式
- 🖼️ **多分辨率支持** - 480p/720p/1080p可选
- 🎭 **多主题** - 蓝色/绿色/紫色/橙色/粉色/随机
- 🎬 **多场景模式** - 按句子分割成多个场景
- 📜 **历史记录** - 保存生成记录

## 🚀 快速开始

### 1. 安装依赖

```bash
cd /workspace/demo
pip install -r requirements.txt
```

### 2. 安装FFmpeg（必须）

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install ffmpeg
```

**macOS:**
```bash
brew install ffmpeg
```

**Windows:**
下载并安装 FFmpeg: https://ffmpeg.org/download.html

### 3. 运行应用

```bash
streamlit run app.py
```

### 4. 浏览器访问

打开浏览器访问: `http://localhost:8501`

## 📖 使用说明

### 基本使用

1. 在文本框中输入你想转换的内容
2. 或者从下拉菜单选择示例文本
3. 在侧边栏设置分辨率、主题颜色、模式等
4. 点击"🎬 生成视频"按钮
5. 等待视频生成完成（约10-30秒）
6. 预览并下载生成的视频

### 设置选项

**分辨率:**
- 480p (854x480) - 快速生成
- 720p (1280x720) - 平衡
- 1080p (1920x1080) - 高清（推荐）

**主题颜色:**
- 随机 - 每次生成随机颜色
- 蓝色、绿色、紫色、橙色、粉色 - 固定主题

**生成模式:**
- 单场景 - 一个视频片段
- 多场景 - 按句号分割成多个场景

## 💡 使用建议

1. **文本长度** - 建议100-500字，语音时长约10-60秒
2. **标点符号** - 使用句号来分割内容，多场景模式效果更好
3. **生成速度** - 1080p视频需要更多时间，测试建议先用720p
4. **输出位置** - 视频会保存在demo目录下

## 🔍 工作原理

```
用户输入文本
    ↓
TTS语音生成 (gTTS)
    ↓
创建渐变背景
    ↓
添加文字和标题
    ↓
合成音视频
    ↓
导出MP4文件
```

## ❓ 常见问题

**Q: 报错"ffmpeg not found"?**
A: 确保已正确安装FFmpeg并添加到系统PATH。

**Q: 生成速度很慢？**
A: 尝试降低分辨率到720p或480p。

**Q: 中文字体显示异常？**
A: 确保系统安装了中文语言包（SimHei字体）。

**Q: 视频文件在哪里？**
A: 视频保存在demo目录下，文件名包含时间戳。
